# 정의

## 하드웨어 스레드

- CPU의 물리적인 코어 내부에서 연산 장치의 놀고 있는 시간을 최소화하기 위해 만든 가상의 실행 통로다. 
- CPU 내부에는 초고속 저장 공간인 레지스터 세트가 존재하는데, 물리 코어 하나에 이 레지스터 세트를 여러 개 두어, 하나의 코어가 마치 여러 개의 작업을 동시에 처리하는 것처럼 OS를 속이는 기술(예: 하이퍼스레딩)을 의미한다. 

## 소프트웨어 스레드

- 실행 중인 프로그램(프로세스)은 OS로부터 독립된 메모리 공간을 할당받는다. 
- 스레드는 이 할당받은 프로세스의 메모리 안에서 임의로 만들어내는 독립적인 실행 흐름이다. 
- 하나의 프로세스 내부에서 실행되므로 모든 것을 따로 쓰면 비효율적이다. 따라서 자원을 공유하는 부분과 독립적인 부분이 나뉜다. 
    - 공유되는 부분 (프로세스 자원) : Code, Data, Heap 
    - 공유되지 않는 독립적 부분 : Stack, PC(Program Counter) 레지스터 

# CPU가 스레드를 실행하는 방법

## 시분할(Time Sharing)

- 단일 코어(혹은 하나의 하드웨어 스레드) 기준으로 CPU는 한 번에 단 한 줄의 코드만 읽을 수 있다. 
- 따라서 하나의 코어가 여러 작업을 동시에 실행하는 것은 불가능하며, 매우 빠른 속도로 스레드를 번갈아 가며 실행해 동시에 처리되는 것처럼 보이게 만든다. (동시성, Concurrency) 

> **이러한 목적을 가지고 시간 조각을 나누어 실행하는 시스템을 시분할 시스템이라고 한다.** 

## 문맥 교환(Context Switching)

> 시분할을 실제로 구현하기 위해 CPU가 기존 작업을 멈추고 다음 작업으로 갈아타는 실제 기술적 행위(수단)다. 

## 동작 과정

1. **스레드 A 연산**: CPU가 스레드 A의 PC(Program Counter)가 가리키는 주소의 코드를 읽어 연산한다. 
2. **상태 저장**: OS 스케줄러에 의해 "스레드 A를 멈추는 지시"가 내려지면, CPU는 현재 레지스터 값들과 PC값을 OS가 관리하는 커널 공간의 TCB(Thread Control Block)에 안전하게 기록하고 스레드 A를 중단한다. 
3. **스레드 B 연산**: CPU가 다음 실행할 스레드 B의 TCB에서 과거에 멈췄던 PC값과 레지스터 상태를 CPU로 복원(Restore)해와서, 멈췄던 부분부터 연산을 이어간다. 

## 결론

- 시분할(Time Sharing)은 정책이자 목적이고, 이를 실현하기 위한 미시적인 기술적 수단이 문맥 교환(Context Switching)이다. 

# 비동기와의 관계

- CPU 하드웨어 자체는 '비동기'라는 개념을 모른다. 명령어 포인터(PC)가 가리키는 줄을 순차적으로 실행할 뿐이다. 
- CPU는 다른 곳을 보고 있는 동안 원래 하던 일을 동시에 뒤에서 진행시키는 초능력이 없다. 

> 그렇다면 비동기라는 단어는 왜 나온 걸까? 

- 스레드에서 코드가 진행되다가 오래 걸리는 작업(디스크 I/O, 네트워크 요청 등)을 만났을 때, CPU를 아무것도 안 하는 대기 상태(Blocking)로 두지 않고, 다음 연산(코드)으로 제어권을 넘겨 CPU 사용률을 극대화하는 프로그램 활용의 지혜를 의미한다. 

# 비동기가 실제로 구현되는 방법

> 프로그래밍 언어에서 비동기를 호출하고 콜백을 받을 수 있는 이유는, CPU 혼자 일하는 게 아니라 CPU 외부의 하드웨어(커널 및 하드웨어 제어기)들에게 작업을 넘기기 때문이다. 

1. **작업 위임**: 
	- 코드를 읽다가 "네트워크에서 파일 다운로드" 명령을 만나면, CPU는 본인이 대기하지 않고 커널을 통해 NIC(네트워크 카드)라는 외부 하드웨어 장치에 일을 맡긴다. 
2. **다음 작업 진행**: 
	- 작업을 넘긴 CPU는 곧바로 다음 라인의 코드로 넘어가 제 할 일을 계속한다. 
3. **완료 및 인터럽트**: 
	- NIC가 파일 다운로드를 마치면, CPU에게 전기 신호인 하드웨어 인터럽트(Interrupt)를 보낸다. 
4. **콜백 실행**: 
	- 신호를 받은 CPU는 (혹은 OS의 이벤트 루프 메커니즘을 통해) 하던 일을 조율하고, 네트워크 카드가 받아온 데이터를 확인한 뒤 등록해 둔 콜백 함수로 GOTO(Jump)하여 남은 작업을 처리한다.
