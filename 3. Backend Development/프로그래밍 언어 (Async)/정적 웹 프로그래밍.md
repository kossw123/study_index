## 왜 필요할까?

- **인프라 비용의 최소화 및 초고속 전송:** 서버가 클라이언트의 요청을 받을 때마다 매번 복잡한 비즈니스 로직을 연산하거나 데이터베이스를 조회할 필요가 없다. 이미 완성된 형태의 정적 리소스를 그대로 밀어내기만 하면 되므로, 서버 부하가 극도로 낮고 사용자에게 압도적으로 빠른 초기 전송 속도를 보장한다.

## 정의

- **정적 웹 프로그래밍 (Static Web Programming)**은 서버가 클라이언트의 요청을 받았을 때 실시간 연산 없이, **미리 디스크나 메모리에 저장되어 있는 고정된 파일들(HTML, CSS, JavaScript, 이미지 등)을 그대로 전달하는 방식**이다.
- **⚠️ [교정] 화면 동작과의 분리:** 서버가 정적 파일(Static Files)을 배포했다고 해서 사용자가 무조건 움직이지 않는 고정된 화면만 보는 것은 아니다. 브라우저가 다운로드한 JavaScript 엔진을 통해 클라이언트 사이드(사용자 브라우저 런타임) 환경에서 화면을 동적으로 조작하고, 외부 API 서버와 비동기 통신(Fetch/Axios)을 수행하여 실시간 데이터를 화면에 반영하는 구조(현대의 SPA 아키텍처)를 완벽히 구현할 수 있다.

## 알아둬야 할 핵심 네트워크 및 웹 표준 컴포넌트

### 1. 클라이언트와 서버의 소프트웨어적 정의
- **클라이언트 (Client):** 네트워크를 통해 특정 서비스를 요청(Request)하고 자원을 소비하는 **프로그램** 역할을 뜻한다. (예: 웹 브라우저, 모바일 앱 등)
- **웹 서버 (Web Server):** 클라이언트의 HTTP 요청을 수신하여 해당하는 정적 파일이나 프록시 이점을 처리하고 응답(Response)을 제공하는 **전문 서버 프로그램**을 뜻한다. (예: Nginx, Apache HTTP Server)
- *※ 둘은 물리적인 컴퓨터 장비(Hardware) 자체가 아니라, 네트워크 아키텍처 상에서의 소프트웨어적 역할 분담이다.*

### 2. 인프라와 서비스의 관계 구정
- **인전넷 (Internet):** 전 세계의 수많은 컴퓨터 장비와 네트워크 망을 물리적으로 얀결해 주는 **인프라 하드웨어 통신망(고속도로)**을 의미한다.
- **WWW (World Wide Web):** 인터넷이라는 거대한 인프라 위에서 하이퍼텍스트 문서들을 하이퍼링크로 연결하여 전 세계 유저가 공유할 수 있도록 만든 **하나의 웹 서비스(고속도로 위의 자동차)**이다. 
- **HTTP 프로토콜 (HyperText Transfer Protocol):** 바로 이 WWW 서비스 공간 안에서 웹 서버와 클라이언트가 HTML 문서 및 각종 정적/동적 데이터를 안전하고 정확하게 주고받기 위해 약속한 **애플리케이션 레이어 통신 규약(교통 규칙)**이다.

### 3. 프론트엔드 3대 자산의 본질적 역할
- **HTML (HyperText Markup Language):** WWW 공간에 노출될 웹 페이지의 논리적 뼈대(구조)와 의미적 정보(Semantic)를 정의하는 표준 마크업 언어이다.
- **CSS (Cascading Style Sheets):** HTML로 설계된 구조 위에 폰트, 디자인, 정렬, 레이아웃 등 시각적인 스타일을 입혀 가독성을 높이는 디자인 명세 언어이다.
- **JavaScript (JS):** 웹 브라우저 환경에서 실행되는 스크립트 프로그래밍 언어로, 사용자의 클릭/입력에 반응하는 상호작용(Interaction) 제어, DOM 트리 조작, 외부 백엔드 API 서버와의 비동기 통신 인터페이스를 담당하는 핵심 동적 엔진이다.

## 프로젝트에서는 어디에서 사용하는가?

- **프론트엔드 배포 아키텍처:** 우리 프로젝트의 프론트엔드 영역(React + Vite)은 철저히 정적 웹 프로그래밍의 배포 아키텍처를 따른다. 
- **구동 매커니즘:** 빌드 도구(Vite)를 통해 전체 소스코드를 순수한 정적 파일(HTML, CSS, JS) 묶음으로 컴파일하여 압축 패키징(Dist)한다. 운영 배포 시 이 고정된 자산들을 **Nginx 웹 서버**가 클라이언트에게 정적으로 서빙(Static File Serving)해 주며, 사용자의 브라우저로 흘러 들어간 JavaScript 코드가 내장된 비동기 통신을 가동하여 뒤편의 **FastAPI 백엔드 서버(동적 API 엔진)**와 연동하는 모던 아키텍처 스타일을 채택하고 있다.
