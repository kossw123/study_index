# 📌 스레드(Thread)와 동기/비동기(Sync/Async) 대응 관계 정리

스레드의 개수(단일/다중)와 작업의 처리 방식(동기/비동기)은 서로 결합하여 총 4가지의 조합을 만들어냅니다. 쉽게 이해할 수 있도록 비유와 예시 코드로 정리했습니다.

---

## 1. 싱글스레드 + 동기 (Single-threaded Synchronous)
> **"한 명의 일꾼이 하나의 일을 순서대로 끝내는 가장 기본적인 흐름"**

* **개념:** 코드가 위에서 아래로 한 줄씩 실행되며, 앞의 작업이 완전히 끝나야만 다음 작업으로 넘어가는 가장 표준적인 코드 흐름입니다.
* **비유:** 요리사 한 명이 주문을 받아서 라면을 다 끓여 손님에게 내어준 뒤에야, 다음 주문을 받아 김밥을 만드는 방식입니다.
* **예시 코드:**
  ```python
  import time

  def task(name):
      print(f"{name} 시작")
      time.sleep(2)  # 2초 동안 메인 흐름이 완전히 멈춤 (Blocking)
      print(f"{name} 완료")

  task("A")
  task("B")  # A가 완전히 끝나야만 실행됨
  ```

## 2. 싱글스레드 + 비동기 (Single-threaded Asynchronous)
> **"일꾼은 단 한 명이지만, 대기 시간이 생기면 즉시 다른 일을 찾아 처리하는 멀티태스킹"**

* **개념:** 파이썬의 `asyncio`나 자바스크립트(Node.js)의 핵심 동작 방식입니다. 스레드는 하나뿐이지만, 어떤 작업(네트워크 요청 등)을 던져두고 기다리는 시간(Idle time) 동안 가만히 있지 않고 다른 작업을 처리합니다.
* **비유:** 요리사 한 명이 가스불에 냄비를 올려두고(비동기 요청), 물이 끓는 것을 가만히 기다리지 않고 그 사이에 도마로 가서 야채를 써는 방식입니다.
* **예시 코드:**
  ```python
  import asyncio

  async def task(name):
      print(f"{name} 시작")
      await asyncio.sleep(2)  # 2초 기다리는 동안 제어권을 시스템에 양보 (Non-blocking)
      print(f"{name} 완료")

  async def main():
      # 두 작업을 동시에 던져두고 이벤트 루프가 알아서 번갈아 처리
      await asyncio.gather(task("A"), task("B")) 

  asyncio.run(main())
  ```

## 3. 멀티스레드 + 동기 (Multi-threaded Synchronous)
> **"여러 명의 일꾼을 고용했는데, 각 일꾼들은 자기 맡은 일을 처음부터 끝까지 순서대로만 하는 흐름"**

* **개념:** 스레드는 여러 개(`threading.Thread`)를 만들어서 동시에 출발시켰지만, 각 스레드 내부에서 일어나는 작업들은 위에서 아래로 순차적으로(동기식으로) 실행되는 방식입니다. 파이썬에서 스레드를 활용해 웹 크롤링을 여러 개 동시에 돌릴 때 가장 많이 쓰는 형태입니다.
* **비유:** 푸드코트에 요리사 2명을 고용했습니다. 1번 요리사는 A 손님의 라면을 처음부터 끝까지 끓이고, 동시에 2번 요리사는 B 손님의 김밥을 처음부터 끝까지 만듭니다.
* **예시 코드:**
  ```python
  import threading
  import time

  def task(name):
      print(f"{name} 시작")
      time.sleep(2)  # 이 스레드는 멈추지만, 다른 스레드는 영향을 받지 않음
      print(f"{name} 완료")

  # 두 일꾼을 동시에 출발시킴 (동시성 확보)
  t1 = threading.Thread(target=task, args=("A",))
  t2 = threading.Thread(target=task, args=("B",))

  t1.start()
  t2.start()  # t1이 sleep으로 멈춰있어도 t2는 동시 시작됨
  ```

---

## 4. 멀티스레드 + 비동기 (Multi-threaded Asynchronous)
> **"여러 명의 일꾼이 각자 여러 개의 논블로킹 작업을 종횡무진 처리하는 극강의 동시성"**

* **개념:** 가장 복잡하지만 대규모 시스템에서 극적인 성능을 낼 때 씁니다. 여러 개의 스레드가 존재하고, 그 스레드들마저도 내부 작업이 멈추지 않도록 비동기 함수를 호출하는 방식입니다. 파이썬에서는 `asyncio` 안에서 CPU 연산이 오래 걸리는 작업을 스레드 풀(`run_in_executor`)로 던질 때 이 구조가 형성됩니다.
* **비유:** 대형 레스토랑에 요리사가 5명(멀티스레드)이 있고, 각 요리사들은 저마다 타이머를 여러 개 맞춰두고 오븐과 가스레인지를 동시에 제어하며 현란하게 음식을 만드는 방식입니다.

---

## 📌 한눈에 보는 요약 표

| 구분 | 동기 (Synchronous) | 비동기 (Asynchronous) |
| :--- | :--- | :--- |
| **싱글스레드** | 가장 단순한 순차 실행.<br>(앞 작업이 막히면 전체가 멈춤) | 일꾼은 하나지만 멈춤 없이 일함.<br>(파이썬 `asyncio`, JavaScript) |
| **멀티스레드** | 독립된 일꾼들이 각자 순차 실행.<br>(파이썬 `threading` 크롤러) | 여러 일꾼이 비동기 작업까지 처리.<br>(대규모 서버 백엔드, 복합 아키텍처) |

* **💡 핵심 요약:** 스레드는 **"일꾼이 몇 명인가(물리적 공간)"**의 문제이고, 동기/비동기는 **"일을 멈추지 않고 효율적으로 처리하는가(작업 방식)"**의 문제입니다.
