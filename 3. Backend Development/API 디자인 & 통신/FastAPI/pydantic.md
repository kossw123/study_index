## 왜 필요할까?

- **강력한 데이터 유효성 검증:** 파이썬의 표준 타입 힌트 구문을 기반으로 런타임 환경에서 복잡한 입력/출력 데이터의 형식을 엄격하게 검증한다.
- **데이터 파싱 및 자동 형변환 (Data Parsing):** 들어오는 데이터 유형이 선언된 타입과 정확히 일치하지 않더라도, 안전하게 형변환(Casting)이 가능한 경우(예: 문자열 `"25"`를 정수 `25`로 변환) 자동으로 데이터를 규격화해 준다.

> ⚠️ **[구분] FastAPI와의 기능적 역할 분담**
> 데이터 검증 실패 시 자동으로 `422` HTTP 에러 응답을 구성하여 반환하고, 모델 정보를 파싱해 대화형 대시보드인 **Swagger UI 문서로 자동 생성해 주는 기능은 'FastAPI' 프레임워크가 제공하는 통합 기능**이다. Pydantic은 그 기반이 되는 데이터의 스펙(Schema) 정의와 유효성 검사 엔진 역할을 담당한다.

## 정의

- 파이썬 타입 힌팅을 극대화하여 데이터의 검증(Validation), 정제(Parsing), 그리고 직렬화(Serialization)를 수행하는 **파이썬의 독보적인 데이터 유동성 검증 라이브러리**이다.

## 동작 과정

Pydantic은 `BaseModel`을 상속받아 우리가 원하는 데이터의 '틀(스키마)'을 형성한다.

```python
from pydantic import BaseModel

class LoginRequest(BaseModel):
    username: str | None = None  # 타입 힌트와 기본값을 선언하여 유효성 검사 기준 마련
    password: str
```

- 클라이언트의 요청 데이터가 엔드포인트로 유입되면, FastAPI는 내장된 Pydantic 모델을 구동하여 값이 누락되었거나 타입이 올바르지 않은지 런타임 검사를 수행한다. 규격에 부합하면 파이썬 객체로 즉시 다룰 수 있게 보장한다.

## Pydantic의 성능 아키텍처 고찰 (V1 ➔ V2 변화)

### 1. 과거(V1) 성능 오버헤드의 본질
과거 Pydantic V1 환경에서 대량의 데이터를 다룰 때 성능 저하가 발생했던 근본적인 원인은 캐스팅이나 단순 복사(Deep copy) 때문만은 아니다. **순수 파이썬(Pure Python) 언어 레벨에서 대규모 인스턴스의 속성을 런타임에 매번 리플렉션하고 유효성 루프를 돌리는 구조적 속도 한계**가 가장 큰 원인이었다.

### 2. V2의 혁신: Rust 기반 코어 엔진 탑재
이러한 언어적 한계를 극복하기 위해, **Pydantic V2는 핵심 데이터 유효성 검증 루프 엔진(`pydantic-core`)을 시스템 언어인 Rust로 통째로 재작성(Rewrite)**하여 출시되었다. 
- 이를 통해 파이썬 런타임 오버헤드를 극적으로 걷어내어, 이전 버전 대비 **최소 5배에서 최대 50배 이상의 강력한 성능 향상**을 달성했다.

### 3. `model_validate_json()`의 최적화 원리
- **V2 기법:** JSON 문자열을 파이썬 딕셔너리로 1차 파싱한 뒤 다시 Pydantic 객체로 변환하는 `model_validate(json.loads(data))` 방식과 달리, `model_validate_json(data)`은 Rust로 작성된 초고속 파서가 JSON 문자열에서 Pydantic 모델 객체로 중간 오버헤드 없이 직행한다.
- **실무 주의:** 단, 이미 프레임워크 단에서 JSON 파싱이 완료되어 딕셔너리 형태로 데이터가 들어오는 환경이거나, 파이썬으로 작성된 무거운 커스텀 검증기(`@field_validator`)가 다수 포함된 구조라면 **컨텍스트에 따라 성능 개선 폭이 다를 수 있으므로 무조건적인 맹신보다는 실제 프로파일링(측정)을 거쳐 최적화 지점을 찾아야 한다.**

## 프로젝트에서는 어디에서 사용하는가?

- **DTO(Data Transfer Object) 설계:** 외부 클라이언트가 던지는 요청(Request Body) 검증용 모델뿐만 아니라, DB 데이터를 조회해 안전하게 필요한 필드만 걸러서 내보내는 응답(Response Model) 스키마 정의에 전면 채택하여 활용 중이다.
