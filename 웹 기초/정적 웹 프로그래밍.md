
웹 서버에 미리 보여줄 페이지를 저장해 놓고 브라우저에서 요청할 경우 그대로 전달하는 방법이다. 따라서 사용자는 페이지가 변경되지 않는 한 고정된 웹 페이지를 보게 된다. 

기본적으로 단순하게 다음과 같이 1:1 통신을 한다.


```
클라이언트 <-> 서버
```

### 알아둬야 할 기본 내용

1. [웹 서버:] 
    1. 클라이언트가 정보를 요청할 컴퓨터를 의미한다. 
    2. 반대로는 클라이언트에게 서비스를 제공할 컴퓨터를 의미한다.
2. [클라이언트]:
    1. 네트워크로 서버에 접속한 후 서버로부터 서비스를 받는 컴퓨터를 의미한다.
3. [HTTP 프로토콜]:
    1. www서비스를 제공하는 통신 규약이다. 
    2. 즉, world wide web이라는 인터넷(네트워크)로 연결된 통신망을 이용하기 위해 사용되는 규칙이다.
4. [HTML]:
    1. www 서비스를 제공하기 위한 표준 언어
5. [Javascript]:
    1. 웹 페이지의 동적인 기능을 제공하는 스크립트 언어
    2. 여기서 동적인 기능이란 데이터가 고정되지 않고 사용자의 행동이나 실시간 데이터에 따라 화면이 변화하는 과정을 의미한다.
6. [css]: 
    1. HTML 문서에서 서체나 색상, 정렬 등 세부적인 디자인에 관련한 여러 기능을 제공한다.
