## 왜 필요한가?

웹 서버는 정적 파일의 빠르고 효율적인 전송을 위해,
WAS는 복잡한 비즈니스 로직 실행 및 데이터를 가공하기 위해 필요하다.

## 정의

서버는 사용자가 원하는 데이터를 주고 받는 프로그램이다.

- 웹 서버는 클라이언트로부터 요청을 받아, 컴퓨터에 물리적으로 저장되어 있는 정적 콘텐츠를 제공하는 프로그램이다.
- WAS는 웹 서버로부터 요청을 받아 서버에 심어둔 프로그래밍 코드를 실행하고 DB 조회하여 동적 컨텐츠를 제공하는 프로그램이다.

*"즉, 서버는 제공하는 프로그램이다."*
*"그 중 웹 서버는 물리적으로 저장되어 있는 정적 컨텐츠를 제공하고, WAS는 동적 컨텐츠를 제공한다."*

동적 웹 프로그래밍에서 나누는 ‘웹 서버’와 ‘WAS’는 기계가 아닌 프로그램의 역할 분담이다.

- 웹 서버가 제공하는 정적 컨텐츠는 다음과 같다.
	- HTML, CSS, JavaScript 파일, 이미지, 동영상 등
- WAS가 제공하는 동적 컨텐츠는 다음과 같다.
	- 사용자의 입력값, 시간, 로그인 여부에 따라 실시간으로 변하는 데이터와 화면 등


## 프로젝트에서는 어디에서 사용하는가?

- 현재는 WAS만 사용하고 있다.
- 서비스 환경에는 앞 단에 Nginx나 Apache등 프록시 서버를 사용해서 동적으로 구성 가능하다.
