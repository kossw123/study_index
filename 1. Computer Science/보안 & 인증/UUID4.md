

## 왜 필요한가?

- 동적 웹 프로그래밍의 발전에 따라 대규모 서비스 분산 시스템에 데이터베이스의 성능을 최적화 하기 위해 필요하다.

## 정의

- 소프트웨어에서 데이터를 식별하기 위한 128비트의 고유 식별자다.
- 암호학적 의사난수 기반의 식별자다.
	- 오직 하드웨어의 난수 생성기를 통해 만들어진 무작위 비트다.
## 동작 과정

- 128비트 중 버전 표시를 제외한 122비트를 하드웨어 난수 생성기를 통해 생성한다.

## 장점

- 구현이 간단하고 보안성이 매우 높다.
## 단점

- 데이터베이스 인덱싱 성능이 저하된다.


## 용도

- 일반적인 웹 API
- 세션 ID
- Token
