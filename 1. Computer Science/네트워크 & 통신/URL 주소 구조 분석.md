
## 정의

```
http://localhost:3000/users/profiles
```

- http:// (프로토콜)
	- 컴퓨터들이 데이터를 주고 받을 때 사용하는 통신 규칙이다.
- localhost (도메인주소)
	- 이 부분이 도메인 주소다.
	- 인터넷 상에서 컴퓨터의 위치를 나타내는 문자 주소다.
- :3000 (포트 번호)
	- 하나의 컴퓨터(IP)안에서 여러 인터넷 프로그램들이 동시에 통신할 수 있도록, 각 프로그램마다 하나씩 할당해주는 고유한 통신 번호다.
- /users/profiles (경로)
	- 서버 안에서 실제 데이터나 페이지가 위치한 세부 경로를 의미한다.
