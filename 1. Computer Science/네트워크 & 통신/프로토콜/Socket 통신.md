## 왜 필요한가?

## 정의

> 네트워크를 통해 두 개의 프로그램이 실시간으로 데이터를 주고받을 수 있도록 연결해주는 양방향 통신 기술이다.

## 기본 개념

- 소켓(Socket):
	- 프로세스가 네트워크로 데이터를 내보내거나 받기 위해 여는 실제적인 통로(단자)
		- 단자란, 소프트웨어가 서로 소통하는 지점을 의미한다.
- 식별 요소:
	- 소켓은 프로토콜, IP 주소, 포트 번호의 조합으로 고유하게 정의된다.
- 종류:
	- TCP(Stream) : 신뢰성이 중요한 연결 지향형
	- UDP(Datagram) : 속도가 빠른 비연결형

## 동작 과정

1. 서버
	1. 소켓 생성 후 특정 IP와 포트 번호로 bind한다.
	2. 클라이언트의 연결 료청을 기다리는 listen 상태가 된다.
	3. 클라이언트의 요청이 오면 accept를 통해 연결을 수락하고 전용 통신 소켓을 생성한다.
2. 클라이언트
	1. 서버의 IP와 포트 번호로 연결 요청(connect)을 보낸다.
3. 데이터 송수신
	1. 연결이 유지된 상태에서 양방향으로 데이터를 읽고(read/recv) 쓴다(write/send).
4. 연결 종료
	1. 통신이 끝나면 소켓을 닫아(close) 자원을 해제한다.
