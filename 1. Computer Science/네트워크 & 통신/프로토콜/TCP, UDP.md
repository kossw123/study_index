## 정의

- 인터넷으로 데이터를 보낼 때 필요한 두 가지 방법이다.
- TCP와 UDP의 가장 큰 차이점은 데이터 전송의 '신뢰성'과 '속도'입니다.
- 쉽게 비유하자면 TCP는 '등기 우편'이고, UDP는 '전단지 던지기'입니다. 
- 두 프로토콜은 데이터를 네트워크로 보낼 때 목적과 상황에 따라 다르게 사용됩니다.

|   구분   | TCP (Transmission Control Protocol) | UDP (User Datagram Protocol) |
| :----: | :---------------------------------: | :--------------------------: |
|   비유   |        📬 등기 우편 (받았는지 꼭 확인)         |     🪂 전단지 투하 (일단 막 던짐)      |
| 연결 방식  |        연결형 (서버와 먼저 대화 연결 확인)        |      비연결형 (확인 없이 그냥 전송)      |
|  신뢰성   |          매우 높음 (유실되면 재전송)           |      낮음 (유실되어도 신경 안 씀)       |
| 데이터 순서 |           보낸 순서대로 정확히 보장됨           |         순서가 바뀔 수 있음          |
|   속도   |         상대적으로 느림 (확인 절차 때문)         |     비약적으로 빠름 (확인 절차 없음)      |

## TCP, UDP간 차이

### TCP : 신뢰성 중심의 순서 있는 바이트 스트림
- **연결 지향**
	- 데이터를 보내기 전 상대방과 연결을 확립하는 과정(3-way Handshake)이 필요하다.
- **흐름 및 혼잡 제어**
	- 상대방의 수신 능력이나, 네트워크 상태를 보면서 전송량을 조절한다.
- **순서 및 재전송 보장**
	- 데이터에 번호(Sequence Number)를 붙여 순서대로 도착함을 보장하며, 중간에 유실된 데이터는 재전송한다.
	- 즉, 데이터가 끊김없는 하나의 흐름(Stream)으로 이뤄진다.

### UDP : 성능 중심의 독립적인 데이터그램(Datagram)
- 비연결형
	- 사전 연결 없이 목적지 주소만 적어 데이터를 전송한다.
- 기능 미지원
	- TCP가 제공하는 순서 보장, 흐름 제어 재전송 기능이 없다.
- 독립적 전송
	- 데이터를 독립적인 덩어리(Datagram)으로 보내기 때문에, 보낸 데이터가 먼저 도착하거나 중간에 유실되어도 신경쓰지 않는다.
