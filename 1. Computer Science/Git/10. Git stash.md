## 왜 필요한가?

- 현재 진행 중인 미완성 작업을 임시 보관함에 잠시 치워두고, 작업 디렉토리를 깨끗한 상태로 만들기 위해 필요하다.
	 - 진행 중인 작업 유지하며 브랜치 전환
	 - 의미 없는 '임시 커밋' 방지
	 - 최신 코드 원격에서 안전하게 가져오기 (`pull`)


## 정의

- 아직 커밋하지 않은 현재의 변경 사항을, [임시 보관소에 안전하게 저장]하고, [작업 디렉토리를 깨끗한 마지막 커밋 상태로 되돌리는] 명령어다.
	- 작업 디렉토리 청소
	- 임시 보관
	- 유연한 복구

### 주의
- `git stash`는 tracked files의 변경 사항만 가능하다.
- 즉, commit되지 않은 밐밋 변경을 임시 보관한다.

## 동작 과정

```
$ git stash // 현재 작업 임시 보관
$ git stash -u // Untracked files도 보관
$ git stash save "로그인 개발 중" // 메모 남기기
$ git stash list // 보관함 목록 열기
$ git stash pop // 보관된 작업 꺼내고 목록에서 지우기
$ git stash apply // 보관함에 그대로 두고 적용만 하기
$ git stash drop stash@{0} // 특정 작업 삭제
$ git stash clear // 전부 삭제
```
