## 왜 필요한가?

- 저장소 내에서 다른 브랜치로 이동하거나, 과거의 특정 시점(커밋)으로 작업 환경을 전환하기 위해 필요하다.
	- 브랜치 간의 자유로운 이동
	- 과거 기록 확인 및 테스트
	- 실수로 수정한 파일 되돌리기
### 중요 업데이트

- `git checkout` 하나의 명령어가 브랜치 이동과, 파일 복구라는 서로 다른 역할을 동시에 수행하기에, git에서는 다음과 같은 직관적인 이름으로 분리했다.

```
$ git switch // 브랜치 변경(이동)할 때만 사용
$ git restore // 파일 수정을 취소(복구)할 때만 사용
```
### 정의

- 작업 디렉토리의 파일들을 특정 브랜치나 특정 커밋의 상태로 교체하는 명령어다.
	- 작업 환경 전환
	- 과거 시점 탐색
	- 파일 복구
## 동작 과정

현재 `git checkout`은 하위 호환성을 위해 `switch`와 `restore`의 역할을 수행하고 있다.
그러나 현재 가장 많이 쓰이는 기능은 특정 커밋 시점으로 이동할 때 많이 사용한다.

```
$ git checkout <commit id>
```
