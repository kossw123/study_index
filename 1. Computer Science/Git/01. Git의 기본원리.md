## 왜 필요한가?

- 파일의 변경 기록을 추적하고, 여러 사람과 코드를 공유 및 협업하기 위해 사용된다.
	- 버전관리
	- 안전한 팀 협업
	- 브랜치 기능
	- 백업 및 클라우드 연동

## 정의

”Git은 특정 시점의 코드를 스냅샷(Snapshot)을 찍어 저장하는 시스템이다.“

즉, 특정 시점에 프로젝트에 대한 기록이다.


## 동작 과정

- Git은 특정 시점에 스냅샷이라는 전체 상태를 한번에 저장함으로써 저장(Snapshot)한다. 
- 그리고 스냅샷의 파일 내용이 변경되지 않았다면, 
	- 이전 스냅샷 파일의 주소(Hash값)을 가리킴으로써 용량을 아끼거나, 
	- 변경이 많다면 이전 버전을 압축하여 용량을 아낀다.

그리고 특정 시점의 프로젝트에 대한 기록을 commit이라 한다.

그리고 commit에는 메타데이터, 작성자, 메시지, 부모 commit의 객체 ID 대한 tag등이 저장되어 있다.
