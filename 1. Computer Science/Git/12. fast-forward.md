

“Git에서 발생되는 가장 단순한 병합 방식이다.”

```
A -- B -- C (main)
           \
            D -- E (feature)
```

여기서 main 브랜치는 C에서 멈춰있고,

feature 브랜치는 더 진행된 상태다.

```
git checkout main
git merge feature
```

해당 명령어를 실행하면 다음과 같은 커밋 그래프가 된다.

```
A -- B -- C -- D -- E (main, feature)
```

즉, main 브랜치의 브랜치 포인터를 E까지 앞으로 이동(fast-forward) 시켰기 때문이다.

만약

```
A -- B -- C (main)
               \
                D -- E (feature)
```

이 상태에서 main 브랜치에 commit을 한다면, 다음과 같을 것이다.

```
A -- B -- C -- F (main)
	      \
	       D -- E (feature)
```

이때 git merge feature를 한다면 다음과 같을 것이다.

```
A -- B -- C -- F ------ G (main)
	      \            / 
	        D --- E ---
```

이 상태는 main 브랜치를 앞으로 이동(fast-forward)한게 아닌, 새로운 commit을 생성했기 때문에

3-way merge라 한다.
