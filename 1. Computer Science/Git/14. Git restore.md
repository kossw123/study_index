## 왜 필요한가?

- 작업 디렉토리에서 실수로 수정한 코드를 지우고, 마지막 인덱스 상태로 안전하게 되돌리거나, 스테이징 영역에 잘못 올린 파일을 내리기 위해 필요하다.
	- 실수로 수정한 파일의 변경사항 취소 (Discard Changes)
	- 실수로 `git add`한 파일 제외 (Unstage)
	- 작업 영역과 스테이징 영역의 명확한 분리

## 정의

- 작업 디렉토리(Working directory)나 스테이징 영역(Staging area)에 있는 파일들의 변경 사항을 지정한 커밋 상태로 복구(취소)하는 명령어다.
	- 작업 디렉토리 파일 복구
	- 스테이징 취소

## 동작 과정

```
$ git restore <파일명> // 특정 파일 초기화
$ git restore . // 현재 폴더의 모든 수정 파일 일괄 초기화
$ git restore --staged <파일명> // 특정 파일 1개만 스테이징 영역에서 제외
$ git restore --staged . // 스테이징 영역 모든 파일 제외
```

# restore와 reset의 비교

reset은 commit 또는 branch를 대상으로 하는게 좋다.
restore는 파일을 대상으로 하는 게 좋다.
