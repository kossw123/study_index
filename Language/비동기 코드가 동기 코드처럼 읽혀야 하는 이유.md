## 왜 필요한가?
### 1. 무분별한 수많은 코드 블록을 제어할 수 없었다.

```
        // ... 수많은 코드들 ...
              });
            });
          });
        });
      });
    });
```

비동기 작업이 많아질수록 코드의 아랫 부분에 괄호들이 무더기로 쌓인다.
나중에 코드를 수정할 때 “이 괄호가 그 괄호인가?”라는 의문이 들고 이때문에 버그를 찾기가 힘들어진다.

### 2. 비동기 코드로 동기식 코드처럼 작성할 수 있게 해준다.

```
login().then((user) => {
  // 🔒 user 변수는 이 중괄호 안에서만 살아있습니다!
});

// ❌ 함수 블록에서 나오면 user가 누구인지 컴퓨터가 전혀 모릅니다.
console.log(user.id); // 에러 발생!
```

함수 블록 안에서 그 방 안에서 만든 변수는 밖에서 쓸 수 없다.
하지만 async/await를 쓰면 다음과 같이 자유로워 진다.

```
const user = await login();
// ✨ 들여쓰기 방이 없으므로, 아랫줄 어디서든 user를 자유롭게 씁니다.
console.log(user.id); 
```

### 3. 콜백을 쉽게 읽을 수 있게 해준다.
```
login()
  .then(user => {
    getProfile(user.id)
      .then(profile => {
        getPost(profile.lastPostId)
          .then(post => { /* 성공 처리 */ })
          .catch(err => { console.log("게시글 에러"); }); // ❓ 누구의 에러지?
      })
      .catch(err => { console.log("프로필 에러"); }); // ❓ 한참 밑에 있네?
  })
  .catch(err => { console.log("로그인 에러"); });
```

만약 비동기 작업마다 에러 처리를 한다면 코드가 괴물처럼 변해버린다.
성공했을 때 실행되는 코드는 맨 위에 있는데 에러코드는 맨 밑바닥에 역순으로 깔리게 된다.
