Git에서 가장 강력한 복구 기능이다.

Git은 HEAD의 이동기록을 모두 저장하는데, HEAD는 브랜치를 가리키는 포인터이기 때문에, 이동했던 브랜치를 모두 기록한다.

```
git reflog

a1b23 HEAD@{0}: commit: add login
c3d45 HEAD@{1}: reset
f6g78 HEAD@{2}: commit: add product
```

이런식으로 모두 기록하는데, commit은 물론 삭제된 branch, stash까지 복구할 수 있다.

commit을 복구하려면 git reflog를 확인한 후

다음과 같은 명령어를 통해 복구한다.
```
git reflog
HEAD@{1}: commit D
HEAD@{2}: commit C
git reset --hard D
```
이러면 D commit이 복구된다.

branch도 마찬가지다.

```
git reflog
git checkout -b feature <hash>
```

stash 또한 마찬가지다.
