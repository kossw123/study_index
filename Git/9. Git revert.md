되돌리는 commit을 생성한다.

즉,

```
A -- B -- C -- D (HEAD)
```

다음과 같은 상태가 있을 때,

C commit으로 되돌리고 싶다면

```
git revert D
```

해당 명령어를 실행한다.

그러면 다음과 같은 그래프를 가진다.

```
A -- B -- C -- D -- E
```

E commit은 D의 변경을 반대로 적용한다는 commit을 가진다.

이러면 D commit에 다음과 같이 추가되었다고 가정했을 때,

+hello

revert commit을 실행한다면

hello라는 추가 코드가 빠지게 된다.
