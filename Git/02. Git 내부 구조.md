## 동작 과정

Git은 데이터를 객체 형태로 저장한다.

즉, 코드처럼 하나의 객체에 여러 데이터를 담아 저장한다.

Pseudo code로 치면 대략 다음과 같을 것이다.

```
class Current():
	blob // 파일 내용
	tree // 디렉토리
	commit // 현재 버전에 대한 변경사항이나 parent
	tag // 특정 commit 이름
```

이런 객체를 특정 시점마다 저장하고 commit을 이동하여 코드를 관리한다.

대략 다음과 같을 것이다.

[current1, current2, current3, ....]

처음으로 돌아가고 싶다면 current1에 대한 태그를 가져와서 blob, tree를 덮어씌우는 식으로 변경한다.
