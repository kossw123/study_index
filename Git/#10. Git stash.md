작업을 임시로 보관하는 명령어다.

개발하다보면 현재 작업중인 브랜치에서 다른 브랜치에서 이슈가 발생했다면, 현재 저장되어 있는 코드를 보관해야 하는 상황이 발생한다.

이때 사용되는 것이 stash다.

```
git stash
```

해당 명령어를 실행하고,

```
git checkout issue
```

이슈가 생긴 브랜치로 넘어가서 다시 작업 후

```
git stash pop
```

다시 작업물을 꺼낸다.

여러 작업을 동시에 하는 경우 stash를 여러개 저장하여 사용할 수도 있다.

```
git stash list // statsh list 확인
git stash apply stash@{0} // 특정 stash 적용
git stash drop stash@{0} // 특정 stash 삭제
```
