조금만 생각해보면, Git은 어찌됐든 OS의 파일 시스템을 이용한 프레임워크다. 그렇다면 파일 시스템의 능력 밖에 있는 일들은 할 수 없다.

즉, CRUD 기능에서 벗어나지 않는다.

"Merge 같은 두 개의 파일을 합치는 듯한 행위도, 사실 두 개의 파일을 하나의 파일로 저장하는 것이다.“

```
D -- E (dev)
/
A -- B -- C (main)
```

dev와 main 브랜치는 각각 코드를 다른 버전으로 수정했지만, 하나로 합치기 위해서 두 commit에 대한 정보를 하나의 파일로 합친다.

```
  D -- E (dev)
 /       \
A -- B -- C -- F (main)
```
