특정 commit 또는 브랜치의 내용을 Working directory에 가져오는 것을 의미한다.

```
git checkout main
```

명령어를 친다면 다음과 같은 상태가 된다.

```
A ─ B ─ C (main)
```

그리고 현재 main 브랜치의 구조는

```
HEAD → main → C
```

HEAD는 main 브랜치를 가리키고, main 브랜치의 포인터는 C commit을 가리킨다.

그리고 Working Directory에는 C파일의 상태가 펼쳐져 있다.

이 상황을

“현재 main 브랜치가 checkout 되어 있다.”

라고 표현한다.

checkout은 브랜치만 펼치는게 아닌 commit도 펼칠 수 있다.

```
git checkout B
```

그러면 구조가 다음과 같아진다.

```
HEAD → B
```

HEAD는 B commit을 가리키게 된다.

그리고 Working directory는 B commit 상태의 파일을 펼친다.

“그리고 이 상태가 바로 Detached HEAD의 상태다.”
