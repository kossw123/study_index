## 왜 필요한가?

- 파이썬으로 만든 코드가 자바로 만든 코드의 내부를 직접 읽을 수는 없다.
- 읽으려면 프로그램이 다른 프로그램의 내부 데이터나 핵심 코드를 직접 읽어야 하는데, 그건 위험하기 그지 없다.
- 또한 앱을 만드는데 다른 프로그램의 데이터를 필요로 할 때, 다른 프로그램의 데이터를 모두 내 앱에다가 넣는건 비효율적이며, API를 사용해 필요한 데이터만 받아서 사용하는게 효율적이다.

## 정의

- 서로 다른 프로그램들 끼리 소통할 수 있는 인터페이스다.
- HTTP나 JSON 같은 세계 공통의 표준 데이터 형식으로 변환하여 서로 코드를 주고 받는다.

## 동작 과정

```
요청 (Request) -> 인증 및 검사 (Authentication) -> 
처리 (Processing) -> 응답 (Response)
```

## 필수 개념 4가지

1. HTTP method
	- **[GET (조회)]** : 데이터를 가져올 때 쓴다.
	- **[POST (생성)]** : 새로운 데이터를 저장할 때 쓴다.
	- **[PUT / PATCH (수정)]** : 기존 데이터를 고칠 때 쓴다.
	- **[DELETE (삭제)]** : 데이터를 지울 때 쓴다.
2. HTTP status code
	- **[2xx (성공)]** : 요청이 정상 처리되었다는 뜻이다.
	- **[4xx (실패)]** : 요청이 정상 처리되었다는 뜻이다.
		- **[401 Unauthorized]** : 로그인 정보나 API가 틀렸을 때
		- **[404 Not Found]** : 요청한 URL가 존재하지 않을 때
	- **[5xx (서버 잘못)]** : 서버가 터졌거나, 코드에 오류가 생겼을 때
3. JSON 데이터 형식
	- 다음과 같은 양식을 사용한다.
```
{
  "userName": "홍길동",
  "age": 25,
  "skills": ["Python", "JavaScript"]
}
```
4. API키와 보안
	- 비공개 데이터나 개인정보가 담신 API는 보안이 생명ㅇ이다.
		- API Key / Token
			- 서버가 발급해주는 **일종의 비밀번호**, 요청을 보낼 때 이 정보를 함께 달아서 보내야만 서버가 문을 열어준다.
